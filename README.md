## ⚡ Key Highlights & Interactive Architecture

- 🧬 **Interactive Neural Synapse Canvas**: Real-time particle network rendered on HTML5 Canvas responding organically to pointer physics and touch.
- 🌌 **Interactive Technology Universe (10 Connected Domains)**: Connected SVG topology graph linking:
  - *Artificial Intelligence*
  - *Machine Learning*
  - *Deep Learning*
  - *Natural Language Processing (NLP)*
  - *Computer Vision*
  - *Robotics*
  - *Internet of Things (IoT)*
  - *Web Development*
  - *Data Analytics*
  - *Data Science*
- 🏆 **Featured Case Studies Showcase (Top 5 Flagships)**:
  - **SmartBuild AI**: Construction Intelligence Platform (FastAPI + XGBoost + Three.js 2D/3D CAD + Gemini API).
  - **CropSafe AI (Capstone DS3206/DS4105)**: National fertilizer authenticity classifier (94.6% Test Accuracy) & yield loss regressors (R² > 0.96) ground-truthed on 2,002 provincial lab certificates.
  - **Clinical Hospital Readmission Predictor**: Stacking ensemble with Platt probability calibration achieving **Rank #3 Globally 🥉** on Kaggle (ML & AI Nexus 2026).
  - **Sinharaja: The Lost Expedition**: Browser-based first-person 3D tactical survival game in React & Three.js running at 60 FPS without external desktop engines.
  - **Hybrid Low-Light Denoising Pipeline**: NAFNet deep residual backbone & 7-stage classical DSP filters (+160.6% relative gain over baseline) for IEEE Mora SP Cup 2026.
- 📂 **Searchable Systems Archive**: Filterable repository explorer covering 16 verified systems with instant search (`/` shortcut) and deep-dive inspection modals.
- 🧪 **Mini AI Laboratory (Genuinely Functional Demonstrations)**:
  - **NLP Sentiment & Emotion Engine**: In-browser real-time lexical parser, polarity scoring, confidence metrics, emotion vectors (Joy, Urgency, Analytical, Skepticism), and salient token chips.
  - **2D Decision Boundary Classifier**: Interactive spatial playground on Canvas using K-Nearest Neighbors (KNN) to dynamically compute decision partitions and training accuracy.
- 📐 **Inside the Model (ML Lifecycle Pipeline)**: Interactive 7-stage ML engineering pipeline (Problem Formulation → Ingestion → Preprocessing → Feature Engineering → Training → Error Analysis → Deployment) featuring actual case studies from Sahil's verified projects and Python snippets.
- 📸 **Field Operations & Community Expeditions Gallery**: Verified STEM outreach photographs from IEEE WIE HOPE 2.0 (Micro:bit physical computing) and Code Club Sri Lanka (Ratnapura Library) with interactive photo lightbox inspection.
- 🎖️ **Verified Accreditations & Honors**: 13 external industry, university, and competitive certifications (HackerRank SQL, TestGorilla 1st Percentile, Google Coursera, Uni of Moratuwa, AWS SUSL, CodeRally 2nd Place 🥈, ML & AI Nexus 3rd Place 🥉).
- 📜 **Exploration Log**: Continuous tracking of active builds (SmartBuild AI), learning vectors (AWS ML Specialty, PyTorch), and robotics/physical computing horizons (BBC Micro:bit, ROS).
- ⌨️ **Command Console**: `Ctrl+K` / `⌘K` global command palette with fuzzy section and project navigation.

## 💻 Local Testing & Development

Run locally using Python's built-in HTTP server or open directly in any browser:

```bash

git clone https://github.com/sahilkavishka/portfolio.git
cd portfolio

# 2. Run local server
python -m http.server 8000

# 3. Open in browser:
# http://localhost:8000
```
